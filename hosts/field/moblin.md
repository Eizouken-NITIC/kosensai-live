# Ch3 屋外遊撃（iPhone 15 Pro + Moblin）

屋台エリア・行列状況・休憩スペースのゲリラ中継。学内 Wi-Fi での移動運用。
接続先 URL は `hosts/obs/srt-urls.sh` の出力をそのまま使う（手打ち禁止）。

## 1. 機材

| 役割 | 機材 | 備考 |
| --- | --- | --- |
| カメラ | iPhone 15 Pro | 所有 |
| 配信アプリ | [Moblin](https://github.com/eerimoq/moblin)（無料・OSS） | 外部マイク接続時の自動切替が公式 README に明記 |
| マイク | DJI Mic（レシーバー） | 所有 |
| ハブ | Nextorage NX-PDPA1（USB-C ハブ・約 ¥6,980） | PD パススルー付き |
| 給電 | モバイルバッテリー（PD 対応） | ハブ経由で充電しながら運用 |

接続:

```
iPhone 15 Pro
  └ USB-C → Nextorage NX-PDPA1
       ├ USB-C : DJI Mic レシーバー
       ├ USB-C : （将来的に SSD）
       └ PD    : モバイルバッテリー
```

## 2. Moblin の設定

```
プロトコル : SRT
モード     : Caller
宛先       : srt://<OBSマシンのIP>:9003?passphrase=<ch3用>&latency=500000
映像       : H.264 / 1920x1080 / 30fps / 4500 kbps
音声       : AAC / 128 kbps / 48 kHz
```

- **SIM なし Wi-Fi 専用運用**。回線が 1 本なので SRTLA ボンディングは不要（意味がない）
- latency は初期値 500ms。当日の Wi-Fi 品質を見て調整（切れるなら 800ms まで上げる）

## 3. 注意点

- **AP 間ローミングで SRT が数秒切れる可能性あり**
  → NW 班に 802.11r（高速ローミング）対応を確認する。
  → latency を大きめに取るとローミング時のバッファ切れを軽減できる。
- 外部マイク（DJI Mic）は接続すると自動で切り替わるが、**現地で必ず耳で確認**する。
- 発熱でサーマルスロットリングが起きると配信が落ちる。直射日光を避け、ケースを外す。
- **買ったらすぐ「充電しながら 1 時間 SRT 配信テスト」を実施すること**（音切れ・発熱確認）。
  これは調達後の最優先タスク。

## 4. 当日の運用

- 移動前にインカムで本部に一声かける（Ch3 が切れるのは想定内だと共有しておく）
- 電池残量 30% を切ったらバッテリー交換のタイミング
- 切断したら Moblin 側で再接続するだけで復帰する（OBS 側は Listener のまま待っている）
