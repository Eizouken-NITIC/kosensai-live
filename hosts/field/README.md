## Ch1 / Ch2 — ATEM Mini Pro

### 映像の集約

会場内の各カメラ（一眼・PTZ）は HDMI またはワイヤレス送受信機を経由して
ATEM Mini Pro に集約する。現場オペレーターが画角を確認しながら物理ボタンで
スイッチングし、各会場の出力を 1 チャンネルに集約する。

### SRT 送出

ATEM Mini Pro の SRT 配信機能で、本部 OBS の Listener に **Caller** として繋ぐ。

```
Ch1（第一体育館）: srt://<OBSマシンのIP>:9001?passphrase=<ch1用>&latency=200000
Ch2（第二体育館）: srt://<OBSマシンのIP>:9002?passphrase=<ch2用>&latency=200000
```

> ⚠️ **ファームウェアが SRT 送出対応版（9.5〜9.6 以降）であることを実機で確認する。**
> ここは当日まで放置すると詰むポイント。

### PTZ カメラの制御

VISCA over IP 対応機を、複数コントローラーからの同時接続を許可する設定で運用する。

- **現場操作:** 現場端末から構図の微調整・プリセット呼び出し
- **本部操作:** 本部の物理コントローラーから全会場の PTZ を横断操作
- **ハンドオフ:** インカムで「現在現場が操作中」「本部が引き取る」を明示的にやり取りする

この運用が回れば実稼働を 4 人に抑えられる。

### 録画

ATEM ISO で各カメラの生素材を個別収録する（素材提供用）。

## 音声取り込み

### 体育館

PA 卓の AUX 送り（バランス XLR）とアンビマイクを小型ミキサーでミックスし、
ステレオ 3.5mm で ATEM Mini Pro に入力する。

```
PA卓 AUX OUT (XLR) → アイソレーター(ART DTI 等) → XLR 10m → 配信用ミキサー
アンビマイク(Zoom H2n LINE OUT 3.5mm) → DI → XLR 10m → 配信用ミキサー
配信用ミキサー 3.5mm OUT → 30cm → ATEM Mini Pro 3.5mm IN
```

- **アイソレーターは予備ではなく本線に入れる。** PA 卓と配信系で電源系統が異なるため。
- **アンビは DI でバランス化してから引き回す。** 3.5mm アンバランスのまま 5〜10m
  引くとノイズが乗る。DI は軽音部所有のものを借用（購入不要）。
- ミキサーは ATEM のすぐ横に置き、アンバランス 3.5mm は最短に保つ。
- Zoom H2n は軽音部所有、LINE OUT 3.5mm 確認済み。
- Dante は導入コスト（10 万単位）と規模感から見送り。
- **→ 実証必須。** 現状は机上の構成案。
